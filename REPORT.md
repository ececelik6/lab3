# Лабораторная работа №3: линейные модели

## 1. Данные и подготовка

### Линейная регрессия

Для эксперимента использовался датасет `Student_Performance.csv`, содержащий 10000 объектов.

Целевая переменная — `Performance Index`.

В качестве признаков использовались:
- `Hours Studied`;
- `Previous Scores`;
- `Extracurricular Activities`;
- `Sleep Hours`;
- `Sample Question Papers Practiced`.

Категориальный признак `Extracurricular Activities` был преобразован в числовой вид:
- `No` → 0;
- `Yes` → 1.

Пропущенные значения в датасете отсутствуют.

Данные были разделены на обучающую и тестовую выборки в соотношении 80/20 с `random_state=42`.

Для масштабирования признаков использовался `StandardScaler`. Масштабирование обучающей выборки выполнялось с помощью `fit_transform`, а тестовой — с помощью `transform`, чтобы не использовать информацию из тестовой выборки при обучении.

### Логистическая регрессия

Для задачи бинарной классификации использовался датасет `german.csv`, содержащий 1000 объектов и 20 признаков.

Целевая переменная `Creditability` находится в первом столбце. В данных:
- 700 объектов класса 1;
- 300 объектов класса 0.

Пропущенные значения отсутствуют.

Данные были разделены на обучающую и тестовую выборки в соотношении 80/20 с `random_state=42` и параметром `stratify`, чтобы сохранить соотношение классов.

Признаки также были стандартизированы с помощью `StandardScaler`.

## 2. Гипотезы и эксперименты

Линейная регрессия была реализована самостоятельно без использования готового `LinearRegression` из scikit-learn.

Для обучения использовался пакетный градиентный спуск со следующими параметрами:
- learning rate: 0.05;
- количество эпох: 800;
- начальные веса: 0;
- начальное смещение: 0.

В качестве функции потерь использовалась среднеквадратичная ошибка (MSE).

В начале обучения MSE составляла 3428.035. К концу обучения значение MSE уменьшилось до 4.169735849525007.

Бинарная логистическая регрессия также была реализована самостоятельно без использования готового `LogisticRegression` для процесса обучения собственной модели.

Использовался пакетный градиентный спуск со следующими параметрами:
- learning rate: 0.1;
- количество эпох: 1000;
- начальные веса: 0;
- начальное смещение: 0;
- порог классификации: 0.5.

В качестве функции потерь использовалась бинарная кросс-энтропия (BCE).

Начальное значение BCE составило 0.6931471805599435, а после обучения — 0.4821317630032231.

Для сравнения использовались три модели:
- собственная логистическая регрессия, реализованная с помощью пакетного градиентного спуска;
- `DecisionTreeClassifier`;
- `KNeighborsClassifier`.

Все три модели сравнивались на одном и том же разбиении данных. Для собственной логистической регрессии использовалась реализация `train_logistic_classifier`.

## 4. Выводы

Самостоятельно реализованная линейная регрессия успешно обучилась с помощью пакетного градиентного спуска. Значение MSE уменьшилось с 3428.035 до 4.169735849525007 на обучающей выборке, а MSE на тестовой выборке составила 4.082628398521854.

Собственная логистическая регрессия показала ROC-AUC 0.808095, Accuracy 0.770, Precision 0.801282, Recall 0.892857 и F1 0.844595.

На данном тестовом разбиении собственная логистическая регрессия показала более высокие значения ROC-AUC, Accuracy, Precision, Recall и F1, чем `DecisionTreeClassifier`.

По сравнению с `KNeighborsClassifier` собственная логистическая регрессия также показала более высокие значения всех рассчитанных метрик: ROC-AUC 0.808095 против 0.741190, Accuracy 0.770 против 0.720 и F1 0.844595 против 0.810811.

Одной из возможных причин является то, что после стандартизации данных линейная граница решений логистической регрессии хорошо подходит для данного набора признаков. Результаты относятся к использованному разбиению данных с `random_state=42` и не обязательно будут полностью совпадать при другом разбиении.

## 5. Воспроизводимость

Для воспроизводимости экспериментов используется фиксированное значение `random_state=42`.

Разбиение данных выполняется с помощью `train_test_split`.

Для стандартизации признаков используется `StandardScaler`, обученный только на обучающей части данных.

Основные параметры собственных моделей:
- Linear Regression: `learning_rate=0.05`, `epochs=800`;
- Logistic Regression: `learning_rate=0.1`, `epochs=1000`.

Эксперименты можно повторить командой:

`python run_experiments.py`

Полученные численные результаты сохранены в файле `experiment_results.json`.
